# 금융투자업 법령 고정 표본 벤치마크

기준일 2026-11-26 (KST), 운영 런타임 커밋 `f1eea5d1aa62369ba03a20f9d30cc9c21f91d9d6` (PR #56). 이 디렉터리는 검증용이며 운영 MCP의 소스, 공개 도구, 배포 설정을 변경하지 않는다.

## 증거 및 재실행

- `gold-20261126.json`: 기대값 사전 동결, 8개 질의/22개 판정 조건, 원문 식별자와 발췌. 직접 search_law/get_law_text/get_admin_rule 조회로 수작업 선정한 표본이다. 동일 법제처 공급원의 다른 조회 경로를 사용했으며 독립 법률 전문가의 정답 확정은 아니다. FIN-07은 동일 경로 재호출 스모크다.
- `runs/20261126-part1.json` ~ `part4.json`: 실제 호출의 원문 응답, 응답 상태, 클라이언트 경과시간. FIN-06은 MCP isError가 커넥터 INVALID_ARGUMENT로 전파된 예상 부정 사례다.
- `runs/20261126-score.json`: 고정 기대값과 실제 응답의 자동 대조 결과.
- `evaluate.mjs`: 응답 평가기. 한 줄에서 지정 prefix 및 모든 문자열을 확인하고, 누락·중복·다른 baseline을 검출한다. 부정 assertion은 명시 오류 및 정상 인용 확인과 함께 평가한다. 일반 네트워크 오류는 부정 테스트 통과가 아니다.
- `evaluate.test.mjs`: Node 내장 테스트. 8개 통과. 추가 npm 의존성 불필요.

저장된 결과를 재평가:

```sh
node --test benchmarks/financial-law/evaluate.test.mjs
node benchmarks/financial-law/evaluate.mjs benchmarks/financial-law/gold-20261126.json benchmarks/financial-law/runs/20261126-part{1,2,3,4}.json
```

Windows PowerShell에서는 마지막 인자를 4개 개별 파일 경로로 지정한다. 라이브 재측정은 gold의 tool/args를 동일 MCP에서 순차 실행하고, 실제 사용한 런타임 SHA와 원문 응답/상태/경과시간을 새로운 capture로 기록한다. 버전이 개정되면 기존 기대값을 결과에 맞춰 덮어쓰지 말고 원문을 다시 확인하고 신규 날짜 gold를 생성한다. 평가기는 저장된 응답을 재평가하는 도구이지 외부 API를 자동 호출하는 러너는 아니다.

## 후속 결함 후보 및 검증 과제

1. FIN-01: 공식 목록의 구버전 고시 연결과 현행 후보의 독립 인용을 구분 유지. 법적 위임 효력과 모든 경로의 완결은 미확정.
2. FIN-02: 시행규칙 제61조 원문 확인 후 공식 연결 범위 미확인. 원천 공급원 응답과 범위 표기를 따로 검토하고 공식 관계를 임의 추정하지 않는다.
3. FIN-03: 현행 금융투자업규정의 역인용 확인 성공, 공식 목록은 다른 버전. 제목 기반 독립 검색 범위 제한 유지.
4. FIN-06: 잘못된 조문을 차단했으나 커넥터가 오류 응답을 예외 문자열로 전달. 정상 인용과 부정 인용을 함께 보존하는 클라이언트 경험 개선 검토.
5. 차기 독립 기준 표본: 하이일드·코스닥벤처 비율 산정과 예외, 펀드 규약 별도 조건, CB 리픽싱/콜옵션, 공시·보고서식 및 금융투자협회 자율규정. 현행/과거/시행예정의 경계와 부정 사례를 추가하고 전문가 검수 및 더 큰 표본으로 확장.

운영 코드·인증·배포 설정은 변경하지 않는다. PR #56의 기존 1,843개 회귀 테스트는 이번 작업에서 새로 실행하지 않았다. 별도 평가기 테스트 8개만 로컬에서 새로 실행했다.
